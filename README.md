# 合理調整宣導共思平台

## 部署步驟

1. 建立 Google 試算表，選擇「擴充功能 → Apps Script」。
2. 將 `Code.gs` 的內容貼入 Apps Script，儲存後執行一次 `setup`，授予權限。
3. 選擇「部署 → 新增部署作業 → 網頁應用程式」。執行身分選「我」，存取權選「所有人」（若組織政策允許），複製部署後以 `/exec` 結尾的網址。
4. 開啟 `index.html`，將 `PASTE_YOUR_GOOGLE_APPS_SCRIPT_EXEC_URL_HERE` 換成該網址。
5. 將 `index.html` 上傳到 GitHub repository 根目錄；到 Settings → Pages，選擇 Deploy from a branch、main、/(root)。
6. 開啟 GitHub Pages 網址，先測試提交一筆，再到結果頁確認票數與內容，同時檢查試算表是否新增資料。

## 使用說明

- 填答頁：單選「理論、流程、案例、申訴」，填寫最多 800 字後送出。
- 結果頁：顯示票數、百分比、匿名文字回答；每 15 秒重新讀取。
- 不需要參與者登入；請勿輸入學生姓名或其他個人資料。
- 每個瀏覽器分頁僅做基本防重複提交；不是可靠的一人一票身分驗證。
- 本版為方便 GitHub Pages 直接跨網域存取，採用 JSONP 讀寫 Apps Script。**公開部署的端點可以被其他人呼叫，因此不適合敏感資訊，也無法有效阻擋惡意大量提交。** 正式大型活動可改用具備驗證與流量限制的後端。
- 若更新 Apps Script 程式碼，需重新部署新版本，並確保 `index.html` 使用有效的 `/exec` 網址。
- 試算表不要設定為公開共用；公開頁面只呈現主題與回答文字。
