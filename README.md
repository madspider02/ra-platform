## 新功能如何使用

1. 參與者在網站建立姓名、暱稱或匿名身分，完成自己想要填寫的各個區塊，**務必按「儲存」或「發布」**。
2. 登入後，在頁首或左側選單按 **「彙整出我今天的回應」**。
3. 網站會從 Google Sheets 重新讀取該參與者**已成功儲存**的資料，並顯示彙整預覽。
4. 確認內容後，按 **「列印／另存為 PDF」**。在瀏覽器的列印對話框選擇「另存為 PDF / Save as PDF」，即可儲存在個人裝置。

A4 版面適用繁體中文、可跨多頁。PDF 標題含公開顯示稱呼及當天的臺灣日期，例如 `合理調整工作坊_王老師_2026-10-18.pdf`；實際命名可由瀏覽器及使用者自行決定。

**重要：**「今天」指「本次工作坊在輸出時的個人彙整」，不是依資料的提交日期進行篩選。即使過幾天才回來輸出，仍會彙整該帳號目前保存的四區塊回應，日期記載的是**匯出日期**。

### PDF 內容

| 工作坊區塊 | 匯出的個人回應 |
|---|---|
| 一、宣導重點 | 單選主題、應宣導的內容 |
| 二、學校運作 | 三階段各自的「可能問題」及「需要資源」 |
| 三、案例推演 | 阿哲、德德、小紜各案例的主責單位、具體措施、四項原則判斷及理由、爭議或困難 |
| 四、常見問題 | 自己發布且未撤回的問題、自己撰寫且未撤回的回覆；每則回覆附上原提問文字協助辨識 |

未儲存的部分會顯示「尚未填寫」。不會匯出其他教師的答案、全體票選圖、返回代碼或本機未送出的草稿。

## 建議驗收步驟

- 用一位**測試參與者**填寫第 1 區塊，再填第 2 區塊的其中一個階段、第 3 區塊的其中一個案例。
- 第 4 區塊發布一個測試問題，並回覆另一個人的問題。
- 進入「彙整出我今天的回應」，確認這些自己的文字出現，未完成項目顯示「尚未填寫」。
- 點「列印／另存為 PDF」，確認 A4 內容沒有被裁切，且不包含別人的答案與返回代碼。
- 登出並使用返回代碼重新登入，再次檢查彙整頁。
- 驗證全部原有四區塊的填寫、重新編輯、公共結果仍可運作。

## 關於 PDF 輸出方式

本版使用瀏覽器內建列印引擎，而非第三方產生 PDF 的服務：

- **Chrome / Edge（電腦）**：列印視窗「目的地」選「另存為 PDF」即可儲存。
- **Safari（macOS）**：列印視窗左下角的「PDF」選單 →「儲存為 PDF」。
- **手機 / 平板**：系統列印／分享介面的 PDF 儲存位置隨裝置與瀏覽器不同而異。若需正式留存，建議在電腦進行。
- 可在瀏覽器列印設定開啟「背景圖形」保留淡藍色分隔帶；未啟用也不影響文字內容。

PDF 是在參與者的瀏覽器中排版輸出，不需要在 Google Drive 建立額外 PDF 檔案，也沒有外部 PDF 服務收到其內容。

## 隱私與資料界線

- 彙整頁僅依「登入者持有的返回代碼」請求自己的已儲存回應，**不依暱稱搜尋**。返回代碼為簡易存取憑證，請參與者自行保管。
- 第四區塊只含本人提問與本人回覆；為讓回覆具有脈絡，附上被回覆問題的原文（未附上其他人的回覆）。
- 已撤回的問題或回覆不會列在 PDF。
- 請勿填寫或匯出可辨識真實學生身分的疾病、醫療、鑑定與個人資料。
